# 春秋航空 · 广州分队全能助手

春秋航空广州分队一线工具融合平台

## 两种使用方式

### 1️⃣ 快速拆分版（线上首选，首屏秒开）
- 入口：`index.html`（15KB 外壳，约 **52ms** 首屏）
- 三大模块**按需加载**：点击才下载对应系统，加载后缓存不重复请求
- 模块文件：`quiz.html`（培训考核）/ `performance.html`（绩效管理）/ `beauty.html`（美妆话术）

### 2️⃣ 离线单文件版（完全独立）
- `spring-assistant.html`（约 2.2MB，gzip 内嵌三系统，双击即用，无任何依赖）

## 三大模块

- **📚 培训考核（刷题系统）**：题库 / 顺序练习 / 背题 / 错题重练 / 模拟考试 / 错题本 / 收藏 / 成就系统
- **📊 绩效管理**：汇总 / 绩效 / 飞行小时 / 销售 / 个人分析 / 班组排名 / 综合分析 / 档位追踪（含模拟预测警示）/ 智能预警 / 个人画像 / 备份恢复
- **💄 美妆话术**：138 款产品库 / 智能话术匹配（品类·效果·品牌·数量）/ 精选话术套装（含低·中·高性价比三套）/ 话术生成与衔接审查 / 肤质推荐 / 同品比拼 / AI 对话练习

## 维护

- 三系统源码位于本目录 `quiz.html` / `performance.html` / `beauty.html`（改它们即改线上）
- 离线单文件版由 `_gzip_build.py` 从源码构建（改源码后运行 `python _gzip_build.py` 再推送）
- `_check_js.py`：语法校验
- 更新后浏览器若显示旧版，请强制刷新（Ctrl+F5 / Cmd+Shift+R）
