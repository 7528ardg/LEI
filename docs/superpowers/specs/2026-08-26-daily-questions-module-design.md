# 「日常问题」第五板块 设计方案

> 日期：2026-08-26
> 目标：在「春秋航空 · 广州分队全能助手」中新增第五板块「❓ 日常问题」，基于《销售和病假资料.docx》与 4 份 OJT 销售 PPT 整合的离线知识库，支持关键字快速检索。

## 一、背景与目标

现有的三个版本（线上拆分版 `index.html`、离线单文件版 `spring-assistant.html`、4合1 单文件版）均需新增第五板块。板块资料基础为：

1. `销售和病假资料.docx`（销售知识汇总 + 病假细则 + 3 张表格）
2. 4 份销售 OJT PPT（4月 / 5月 / 7月 / 8月，共 25 张截图，细节在图片中）
3. 补充：地面扫码订单可通过小程序直接开电子发票

**核心诉求：离线状态下，输入关键字即可快速定位相关知识点，细节原图可展开查看。**

## 二、已确认的设计决策

| 决策项 | 结论 |
|---|---|
| 方案 | 方案 A：问答式知识库 + 智能搜索 |
| 接入版本 | 全部三个版本（index.html / spring-assistant.html / 4合1） |
| 图片策略 | 25 张 PPT 关键截图全部压缩后 base64 内嵌，完全离线可查 |
| 搜索方式 | 中文模糊匹配 + 同音纠错（输入"转正"可提示"转账"） |
| 标签图标 | 「❓ 日常问题」 |
| 体积 | 接受单文件版增加约 2-4MB |

## 三、板块结构（daily.html）

### 3.1 数据层

约 26 条「问题→答案→原图」知识条目，分 5 个分类：

| 分类 | 知识点（来源） |
|---|---|
| 💰 销售收款 | 收款方式；转账要求与附言格式（日期+航班号+金额）；现金缴存 24h 时限与扣分；学习途径（我的培训→专题→客舱销售专题 29 项）（4月PPT、docx） |
| 📦 配送系统 | 备注使用规范（3 种情况，无需电话报备）；数量修改分类（原库存/配送/补仓/销售/修订）；航班任务 4 步骤（航前确认→获取销售→上传四联单→航后完成）；销转保/保转销（入口：机供品配送(乘务)新）；临时更换飞机流程（原机/新机表格）；航后讲评核查要点；历史教训案例（替代机组餐只能用餐饮类、退回颈枕改原库存、现货误做预售、网络断开案例）（5月PPT、docx） |
| ✈️ 机上销售 | WIFI 订单操作（V2.6.3+、CH-Admin、结束销售、先服务后配送、现金单独缴存）；免税品入境限量表；组合商品销售按系统指引；桌面扫码订单自助开票；退款流程图（现金/原路退回，审核 1-2 天）（7月、8月PPT） |
| 🏥 病假管理 | 病假材料（挂号证明、病历、病假证明 + 医院公章）；SMP 占位日期一致性；申请流程（通知航医→SMP 提交→批复）；12h/20:00 后报备值班经理 18017321071 与 AOC 32315814；3h 内报备分队；单据（药费单原件/病假证明原件/病历复印件/挂号单原件）上交时限（5 日历日 / 每月 30 日规则）；扣分规则（3h 以上首日-100 每日+50 封顶 500；3h 内违规+100；备上航班+200）；医疗观察期；续病假重走流程；工资按政府规定、跨月分月计算（docx / 管理手册 3.1.10.11） |
| 🧾 电子发票 | 地面扫码订单可通过小程序直接开电子发票（补充新增） |

### 3.2 搜索层

- 每条条目标配 `keywords` 标签与别名；搜索匹配范围：问题 + 答案全文 + 关键字标签
- 中文模糊匹配：子串包含 + 同音字替换（拼音双声母匹配）纠错
- 结果排序：精确命中 > 关键字标签命中 > 答案命中；关键字高亮显示
- 热门标签快捷点选：转账 / 病假材料 / 开票 / 现金缴存 / WIFI / 销转保 / 免税品 / 退款
- 空结果给出建议提示

### 3.3 原图层

- PPT 25 张截图经 PIL 压缩（最长边 ≤ 1000px，JPEG q0.85）后 base64 内嵌
- 图片挂载到对应问答答案内，点击放大（lightbox modal）
- 图片带说明文字与来源标注（如「转账附言示例 · 4月OJT」）

### 3.4 UI 层

- 沿用现有主题：--primary #148453、grad-primary、livery 渐变条、深色模式自适应
- 顶部：大搜索框 + 搜索按钮 + 热门标签
- 中部：分类筛选 chips（全部 / 销售收款 / 配送系统 / 机上销售 / 病假管理 / 电子发票）
- 问答列表：卡片式，标题含分类徽章与来源标签，点击展开答案
- 来源标注：如「4月OJT」「5月OJT」「管理手册 3.1.10.11」

5. 三版本均需改 `applyTheme` 的主题联动数组
