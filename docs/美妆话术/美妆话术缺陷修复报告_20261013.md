## 二、逐缺陷修复明细

### R1 · 重置筛选漏清保健品快捷标签
- **现象**：点「🔄 重置」后列表仍显示「筛选结果 3 款」，未被恢复为全量。
- **根因**：`resetAllFilters()` 重置了 `searchQuery / brandFilter / categoryFilter / sortProducts`，唯独漏了 `browseSupplementFilter`。
- **修复**：在 `resetAllFilters()` 中补 `state.browseSupplementFilter = '';`。
- **验证**：真实浏览器点击「护肝」→「重置」：`{supp:"", cat:"all", q:"", brand:"all", sort:"default", hint:"共351款产品"}` ✅

### D1 · 品牌故事规格串写（幸姬梅酒 500ml 段落冒出 720ml）
- **现象**：品牌故事是**品牌级**的，写的是该品牌最有代表性的那一款；同品牌其它款会被带出不属于自己的规格 —— 幸姬梅酒 500ml 段落出现「720ml」（那是同厂特别纯米酒的规格），影响 9 套。扫描后发现同类风险共 6 款产品（斯维诗 3 款、朝日、和汉刚、幸姬梅酒）。
- **修复**（`beauty.html` 新增工具函数 + 4 处注入点改造）：
  1. 新增 `BRAND_SPEC_RE / ownSpecTokens() / stripForeignSpec() / bsField()` 一组全局工具；
  2. 注入品牌故事前，按**当前产品自身**的合法规格集合（volume + 品名 + 说明）过滤，命中库外规格令牌即删除；
  3. 删除后做标点/空格收口，避免「15%、720ml，配鲔鱼」→「15%、，配鲔鱼」这类残渣；
  4. **重删除保护**：若某字段被删规格 ≥2 处（说明这段故事讲的本就是同品牌另一款，如斯维诗一篇全在讲护肝片剂量），直接回退到**受众无关的品牌来历**字段；两个字段都不可用则放弃该段，不输出「只有引导语、没有内容」的半句话；
  5. 4 个注入点统一改造：`brandHeadline()`、`brandLineFor()`、`productTalk()` 的 story/concept 分支、酒类 tip 拼接。
- **验证**：6 款受影响产品 × 20 次生成 = 120 套，**外来规格泄漏 0 套**；幸姬梅酒 500ml 输出「…酒精度 15%，配鲔鱼、鲑鱼、牡蛎。」（清酒 720ml 产品仍正常保留 720ml）；「空引导语」0 套。

### D2 · 素材池与产品数据残留违禁词
- **现象**：`complianceClean` 对「承诺 / 比代购 / 顶级 / 治愈 / 排毒 / 医疗 / 填充」做整词删除或替换，而源数据里就带着这些词 → 15 套合规分被扣，并留下「能的我说清楚，不能的我不含糊」这类残句。
- **修复**（两轮，共 81 处源数据改写）：
  1. **文案改写**：「郑重承诺」→「说句实在话」、「假一赔三做承诺」→「用假一赔三兜底」、「硬承诺」→「硬规矩」、「确保卖家发货」→ 保持、「不是 Free 的承诺」→ 直白改写；「比代购快多了」→「不用等代购转手」；「顶级茉莉花香」→「茉莉花香，清雅高贵」、「日本顶级酒米」→「日本名优酒米」、「顶级抗老面霜」→「高端抗老面霜」；「帮助肝脏排毒」→「帮助肝脏代谢」、「高弹填充棉」→「高弹回弹棉」等。
  2. **短语级兜底**（`PHRASE_FIX`）：补 13 条组合式替换（`'我承诺':'我说到做到'`、`'虚假承诺':'空话'`、`'保障承诺':'实在保障'`、`'不承诺':'不打包票'` 等），即使日后源数据再混进来，输出也不会断句。
  3. **受保护专名**：把「II 类医疗器械 / II类医疗器械 / 医疗器械 / 医用 / III 类医疗器械」加入 `PROTECTED_TERMS` —— 这是敷尔佳敷料的**真实注册分类**，属于事实，不该被清洗改掉（与既有「海洋堇干细胞精萃」保护逻辑一致）。
- **验证**：1100 套**运行时替换次数 = 0**；残句扫描（`，的` / `（ ）` / `、，` 等）**0 套**。

### D3 · 引擎结构自检 `hasMoment` 正则过窄造成误扣分
- **现象**：35~50 套内容完好、明确写了「【使用时刻】…」的话术，因场景词不在穷举列表里被判「缺使用场景」扣 10 分（86 分而非 96 分）。
- **修复**：改为**结构信号优先** —— 正文存在 `【使用时刻】/【场景】/【用法】/【用的时候】/【什么时候用】` 标签行即认定已有场景，再叠加一批场景词（摆在桌上/倒一杯/随餐/朋友来了/待客/下班/洗澡/运动/出差/换季/日照/妆前/吹风 等）兜底。结构与词两者都没有才算真缺场景。
- **验证**：结构自检误扣分由 49 套 → **0 套**。

### D4 · 规格数字被误判为价格且可穿透闸门
- **现象**：「X精华 京东自营 100ml 到手好价」被解析为 ¥100；当同规格无参考价时，100 落在品类兜底区间内可穿透五道闸门进入预览表。
- **根因**：平台词 + 裸数字的规则 `平台[^0-9]{0,6}(数字)` 里，「自营」两个字落在允许的间隔内，紧随其后的 `100ml` 被当成报价。
- **修复**（双闸门）：
  1. `parseSearchPrices` 的平台裸数字正则加**负向前瞻**，把「数字 + 容量/计量单位」整体排除（`100ml / 50克 / 30片 / 500mg / 20%`），不影响「京东1099」这类真实裸数字报价；
  2. `sanitizeAiPrices` 新增第二守卫 `isSpecNumber()`：若该数字在搜索原文里**只以规格形态**出现（没有任何 `¥数字 / 数字元 / 到手价数字` 的用法），判定为规格误读并拒收。
- **验证**：专项回归 8/8 通过（含「同句另有真实价 1280 元仍能解析」「平台裸数字仍可识别」「已录入价位可放行」等正向用例不被误伤）；价格总套件 58/58。

### D5 · 酒类警示语缺主语（自相矛盾）+ 过期 UI 文案
- **现象**：输出「幸姬梅酒500ml：含酒精，禁止饮用。」—— 它本身就是一款酒，句子缺了人群主语，读起来像谁都不能喝。
- **根因**：`prods.forEach → notes.push(name + '：' + u.reason)` 只取了 `reason`，丢掉了 `type`（人群主语）；另一处 `p.unsuitable.map(u => ...)` 渲染也做了同样的主语补全强化。
- **修复**：温馨提示改为 `「产品名：人群——原因。」`； `unsuitable` 渲染处同样保留人群主语。
- **验证**：输出变为「青花汾酒30年复兴版53度：未成年人及孕妇——含酒精，禁止饮用。」✅
- **附带修复**：预览弹窗与批量确认弹窗的过期文案「本版本已停用联网搜索」已更正为与实际能力一致的描述（联网检索实测 1.7~2.4 秒返回、主源失败自动切备用源、双源均失败用历史快照回退）。

## 五、遗留项（非本次缺陷，建议后续迭代）

3. **`R14` 大组合重复句**：建议对【规格】行做跨产品去重。
