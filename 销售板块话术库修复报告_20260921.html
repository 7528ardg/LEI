三、根因修复：5 处数组空洞的来源

beauty.html 里 5 处 },, 并非手误，而是 _apply_souvenir_20260916.py 的 append_scripts() 缺陷：

```python

修复前

add = ''.join(",\n { id: '%s', ... }" % ...) # ← 无条件前置逗号

src = src[:j] + add + src[j:]

```

锚点 j 指向数组收尾 ]，而 src[:j] 的最后一个字符已经是逗号（数组末项的尾逗号），插入后形成 },, → JS 数组 elision（空洞）：.length 虚增 1、filter/map/forEach 静默跳过、任何 scripts[i] 直取都会读到 undefined。

两处一并修复（该补丁命中 souvenirModel / souvenirTravel / souvenirGift / souvenirPlush / souvenirCreative 五个栏目，恰好等于 5 处空洞，验证了因果）：

  1. beauty.html 中 5 处 },, → },
  2. _apply_souvenir_20260916.py：插入前回看锚点前第一个非空白字符，已是逗号则不再前置；同时把原本依赖 ASCII 巧合的幂等判断（chr(len+48)）改为直接检查 id 是否存在
